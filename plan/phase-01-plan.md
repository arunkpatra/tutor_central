# Phase 1 Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A monorepo where `bun check` proves everything, the app builds and launches in the simulator as an empty shell, the database schema and its row-level security run locally with tests, the API answers on Vercel, and CI does the same with caches.

**Architecture:** Three parts in one repo: `ios/` (XcodeGen project, one local Swift package of modules), `supabase/` (migrations, seed, RLS tests), `api/` (Hono on Vercel). `tools/check.ts` runs every check in order with an input-hash cache so unchanged steps are skipped; CI runs the same script on a macOS runner (iOS) and an Ubuntu runner (API and database). No screen is designed or built in this phase (D6).

**Tech Stack:** Swift 6 (language mode 6, strict concurrency), SwiftUI, Swift Testing, XcodeGen, SwiftFormat, SwiftLint, xcbeautify, `supabase-swift`; Supabase CLI with Docker; Bun, TypeScript, Hono, Zod, `@supabase/supabase-js`; GitHub Actions.

**Spec:** `docs/spec.md` sections 4 to 8; scope and acceptance in `plan/phase-01-foundation.md`; decisions D5, D7, D8, D9, D12, D14, D15, D16, D19 in `plan/README.md`.

## Global Constraints

- iOS 26.0 minimum, iPhone only, portrait only (D1). Bundle id `app.journium.tutorcentral` (D19).
- Swift language mode 6 with `SWIFT_STRICT_CONCURRENCY = complete`; SwiftUI only; Observation (D8).
- The `.xcodeproj` is generated by XcodeGen from `ios/project.yml` and never committed (D9).
- `supabase-swift` is the only iOS dependency, pinned to an exact version (D14). API dependencies pinned exactly in `package.json` (no `^` or `~`).
- Bun only on the TypeScript side; never npm, npx, yarn, pnpm (D16).
- Every table has `id`, `centre_id`, `created_at`, `updated_at` and an RLS policy; a table without a policy and a test does not merge (`CLAUDE.md` rule 6).
- No secret in the repo: `.env*` is ignored; `.env.example` lists names only.
- Tests: Swift Testing for Domain and Data; Bun tests for the API and RLS; one launch smoke test; no UI test suites (D15).
- Documents-only changes go to `main` directly; code goes through a pull request with a green check (D12).
- Copy rules apply to anything the app shows, even the placeholder: sentence case, no exclamation marks, no emoji.

## Review Focus

1. `bun check` on a machine without Docker running: the database step must print one line saying it was skipped and why, and the check must still pass. Test in Task 5 (`db` step skip).
2. A user who is a member of no centre (signed up, onboarding not done) must see nothing and be able to call `create_centre` exactly once per name; a second centre for the same owner is allowed by the schema but not by the app, so the RLS test pins that the first call returns a centre the user can read. Test in Task 4.
3. `generate_fees` for a month where some students already have invoices must insert only the missing ones and return that count, and must never insert for archived students. Test in Task 4.
4. A JWT that is well-formed but expired, or for a deleted user, must get `401` with a JSON body, not a `500`. Test in Task 6 (the verifier returns `null` → `401`).
5. `tools/pr-shots.ts` must never touch the working tree or the checked-out branch, so a half-done change is never committed by accident. Test in Task 8 (a dry run against a scratch repository leaves `git status` unchanged).

- [ ] **Step 4: Implement `sh`**

`tools/lib/sh.ts`:
```ts
export type ShResult = { code: number; stdout: string; stderr: string };

export async function sh(
  cmd: string[],
  opts: { cwd?: string; env?: Record<string, string>; inherit?: boolean } = {},
): Promise<ShResult> {
  const proc = Bun.spawn(cmd, {
    cwd: opts.cwd,
    env: { ...process.env, ...opts.env },
    stdout: opts.inherit ? "inherit" : "pipe",
    stderr: opts.inherit ? "inherit" : "pipe",
  });
  const [stdout, stderr] = await Promise.all([
    opts.inherit ? Promise.resolve("") : new Response(proc.stdout).text(),
    opts.inherit ? Promise.resolve("") : new Response(proc.stderr).text(),
  ]);
  const code = await proc.exited;
  return { code, stdout, stderr };
}

export async function must(cmd: string[], opts?: Parameters<typeof sh>[1]): Promise<string> {
  const r = await sh(cmd, opts);
  if (r.code !== 0) throw new Error(`${cmd.join(" ")} failed (${r.code})\n${r.stderr}`);
  return r.stdout;
}
```

Run: `bun test tools/lib` → Expected: 2 pass.

```swift
import Foundation

/// Whole rupees. INR has no fractional fees in this product (D2).
public struct Money: Hashable, Sendable, Comparable, AdditiveArithmetic {
    public let rupees: Int

    public init(rupees: Int) { self.rupees = rupees }

    public static let zero = Money(rupees: 0)

    public static func + (lhs: Money, rhs: Money) -> Money { Money(rupees: lhs.rupees + rhs.rupees) }
    public static func - (lhs: Money, rhs: Money) -> Money { Money(rupees: lhs.rupees - rhs.rupees) }
    public static func < (lhs: Money, rhs: Money) -> Bool { lhs.rupees < rhs.rupees }

    /// "₹1,20,000": Indian grouping, no decimals.
    public var formatted: String {
        rupees.formatted(.currency(code: "INR").locale(Locale(identifier: "en_IN")).precision(.fractionLength(0)))
    }
}

public extension Sequence where Element == Money {
    var total: Money { reduce(.zero, +) }
}
```

- [ ] **Step 6: Implement Period**

`Sources/Domain/Period.swift`:
```swift
import Foundation

/// A fee month. Stored as the first day of the month (`fee_invoices.period`).
public struct Period: Hashable, Sendable, Comparable {
    public let year: Int
    public let month: Int

    public init(year: Int, month: Int) {
        precondition((1...12).contains(month), "month out of range")
        self.year = year
        self.month = month
    }

    /// "2026-03-01" → March 2026; any other day of the month is refused.
    public init?(isoDay: String) {
        let parts = isoDay.split(separator: "-").compactMap { Int($0) }
        guard parts.count == 3, parts[2] == 1, (1...12).contains(parts[1]) else { return nil }
        self.init(year: parts[0], month: parts[1])
    }

    public var isoDay: String { String(format: "%04d-%02d-01", year, month) }

    public var next: Period { month == 12 ? Period(year: year + 1, month: 1) : Period(year: year, month: month + 1) }
    public var previous: Period { month == 1 ? Period(year: year - 1, month: 12) : Period(year: year, month: month - 1) }

    public func start(in timeZone: TimeZone) -> Date {
        var c = Calendar(identifier: .gregorian)
        c.timeZone = timeZone
        return c.date(from: DateComponents(year: year, month: month, day: 1))!
    }

    public static func containing(_ date: Date, in timeZone: TimeZone) -> Period {
        var c = Calendar(identifier: .gregorian)
        c.timeZone = timeZone
        let parts = c.dateComponents([.year, .month], from: date)
        return Period(year: parts.year!, month: parts.month!)
    }

    public var title: String { Self.format(self, "MMMM yyyy") }
    public var shortTitle: String { Self.format(self, "MMM yyyy") }

    private static func format(_ p: Period, _ pattern: String) -> String {
        let f = DateFormatter()
        f.locale = Locale(identifier: "en_IN")
        f.timeZone = TimeZone(identifier: "UTC")
        f.dateFormat = pattern
        return f.string(from: p.start(in: TimeZone(identifier: "UTC")!))
    }

    public static func < (lhs: Period, rhs: Period) -> Bool {
        (lhs.year, lhs.month) < (rhs.year, rhs.month)
    }
}
```

`Sources/Data/SupabaseConfig.swift`:

```swift
import Foundation

/// Where the app finds Supabase. Values come from Info.plist, which the build fills from xcconfig
/// (`SUPABASE_URL`, `SUPABASE_ANON_KEY`). The anon key is public by design; the service role key never ships.
public struct SupabaseConfig: Sendable, Equatable {
    public enum Error: Swift.Error, Equatable { case missing(String), invalidURL }

    public let url: URL
    public let anonKey: String

    public init(info: [String: Any]) throws {
        guard let urlString = info["SUPABASE_URL"] as? String, !urlString.isEmpty else { throw Error.missing("SUPABASE_URL") }
        guard let key = info["SUPABASE_ANON_KEY"] as? String, !key.isEmpty else { throw Error.missing("SUPABASE_ANON_KEY") }
        guard let url = URL(string: urlString), url.scheme?.hasPrefix("http") == true, url.host() != nil else { throw Error.invalidURL }
        self.url = url
        self.anonKey = key
    }

    public static func fromMainBundle() throws -> SupabaseConfig {
        try SupabaseConfig(info: Bundle.main.infoDictionary ?? [:])
    }
}
```

```ts
import { Glob } from "bun";
import { mkdir } from "node:fs/promises";
import { join } from "node:path";

/** sha256 over the sorted matched files (path + contents) and a salt naming the toolchain. */
export async function hashInputs(globs: string[], root: string, salt: string): Promise<string> {
  const files = new Set<string>();
  for (const g of globs) for await (const f of new Glob(g).scan({ cwd: root, dot: false })) files.add(f);
  const h = new Bun.CryptoHasher("sha256");
  h.update(salt);
  for (const f of [...files].sort()) {
    h.update(f);
    h.update(await Bun.file(join(root, f)).arrayBuffer());
  }
  return h.digest("hex");
}

export async function readStamp(step: string, cacheDir = ".check-cache"): Promise<string | null> {
  const f = Bun.file(join(cacheDir, step));
  return (await f.exists()) ? (await f.text()).trim() : null;
}

export async function writeStamp(step: string, hash: string, cacheDir = ".check-cache"): Promise<void> {
  await mkdir(cacheDir, { recursive: true });
  await Bun.write(join(cacheDir, step), hash);
}
```

```ts
import { STEPS, toolchainSalt } from "./check/steps";
import { hashInputs, readStamp, writeStamp } from "./check/cache";

const fresh = process.argv.includes("--fresh");
const only = process.argv.find((a) => a.startsWith("--only="))?.slice(7).split(",");
const salt = await toolchainSalt();
const summary: string[] = [];
const t0 = Date.now();

for (const step of STEPS) {
  if (only && !only.includes(step.name)) continue;
  const started = Date.now();
  const reason = step.skipIf ? await step.skipIf() : null;
  if (reason) { summary.push(`  ${step.name.padEnd(8)} skipped: ${reason}`); continue; }
  const hash = await hashInputs(step.inputs, ".", salt);
  if (!fresh && (await readStamp(step.name)) === hash) { summary.push(`  ${step.name.padEnd(8)} unchanged, not run`); continue; }
  console.log(`\n▶ ${step.name}`);
  try {
    await step.run();
  } catch (e) {
    console.error(`\n✗ ${step.name} failed after ${((Date.now() - started) / 1000).toFixed(1)}s`);
    console.log(summary.join("\n"));
    process.exit(1);
  }
  await writeStamp(step.name, hash);
  summary.push(`  ${step.name.padEnd(8)} green in ${((Date.now() - started) / 1000).toFixed(1)}s`);
}
```

```sql
create function public.generate_fees(p_centre uuid, p_period date) returns integer
language plpgsql security invoker set search_path = public as $$
declare n integer;
begin
  if p_period <> date_trunc('month', p_period)::date then raise exception 'period must be the first of a month'; end if;
  if not public.is_member(p_centre) then raise exception 'not a member' using errcode = '42501'; end if;
  insert into public.fee_invoices (centre_id, student_id, period, amount)
  select s.centre_id, s.id, p_period, coalesce(s.monthly_fee, c.monthly_fee, 0)
  from public.students s left join public.classes c on c.id = s.class_id
  where s.centre_id = p_centre and s.archived_at is null
    and not exists (select 1 from public.fee_invoices f where f.student_id = s.id and f.period = p_period);
  get diagnostics n = row_count;
  return n;
end $$;

create function public.delete_centre(p_centre uuid) returns void
language plpgsql security invoker set search_path = public as $$
begin
  delete from public.centres where id = p_centre and owner_id = auth.uid();
  if not found then raise exception 'not the owner' using errcode = '42501'; end if;
end $$;

grant all on all tables in schema public to authenticated;
grant execute on function public.create_centre(text, text) to authenticated;
```

```ts
import type { MiddlewareHandler } from "hono";

export type Verify = (token: string) => Promise<{ id: string } | null>;
export type Vars = { Variables: { userId: string } };

/** 401 in words for anything but a live user. Never 500: a failed verifier is a sign-in problem to the caller. */
export function makeRequireUser(verify: Verify): MiddlewareHandler<Vars> {
  return async (c, next) => {
    const token = c.req.header("authorization")?.replace(/^Bearer\s+/i, "");
    if (!token) return c.json({ error: "sign in again" }, 401);
    let user: { id: string } | null = null;
    try { user = await verify(token); } catch { user = null; }
    if (!user) return c.json({ error: "sign in again" }, 401);
    c.set("userId", user.id);
    await next();
  };
}
```

```ts
import { Hono } from "hono";
import type { ZodType } from "zod";
import { GenerateInput, ScanRegisterInput, CheckPaperInput } from "../schemas";
import type { Vars } from "../auth";

function validated<T>(schema: ZodType<T>, body: unknown): { ok: true; value: T } | { ok: false; error: string } {
  const r = schema.safeParse(body);
  return r.success ? { ok: true, value: r.data } : { ok: false, error: r.error.issues.map((i) => `${i.path.join(".")}: ${i.message}`).join("; ") };
}

export const aiRoutes = new Hono<Vars>();

for (const [path, schema] of [["/generate", GenerateInput], ["/scan-register", ScanRegisterInput], ["/check-paper", CheckPaperInput]] as const) {
  aiRoutes.post(path, async (c) => {
    const body = await c.req.json().catch(() => null);
    const v = validated(schema as ZodType<unknown>, body);
    if (!v.ok) return c.json({ error: v.error }, 400);
    return c.json({ contract: "Phase 6", route: path, userId: c.var.userId }, 501);
  });
}
```

```ts
#!/usr/bin/env bun
import { basename } from "node:path";
import { must, sh } from "./lib/sh";

export type ShotsOptions = { repo: string; folder: string; files: string[]; push: boolean; author?: { name: string; email: string } };

/** Commit files under <folder>/ on the orphan branch pr-shots using plumbing only: no checkout, no index, no working-tree change. */
export async function commitShots(o: ShotsOptions): Promise<string> {
  const g = (args: string[], env: Record<string, string> = {}) => must(["git", ...args], { cwd: o.repo, env });
  const blobs: string[] = [];
  for (const f of o.files) blobs.push(`100644 blob ${(await g(["hash-object", "-w", f])).trim()}\t${basename(f)}`);
  const folderTree = (await must(["sh", "-c", `printf '%s\\n' ${blobs.map((b) => `'${b}'`).join(" ")} | git mktree`], { cwd: o.repo })).trim();
  const parent = (await sh(["git", "rev-parse", "-q", "--verify", "refs/heads/pr-shots"], { cwd: o.repo })).stdout.trim();
  const existing = parent ? (await g(["ls-tree", parent])).trim().split("\n").filter((l) => l && !l.endsWith(`\t${o.folder}`)) : [];
  const rootTree = (await must(["sh", "-c", `printf '%s\\n' ${[...existing, `040000 tree ${folderTree}\t${o.folder}`].map((b) => `'${b}'`).join(" ")} | git mktree`], { cwd: o.repo })).trim();
  const env = o.author ? { GIT_AUTHOR_NAME: o.author.name, GIT_AUTHOR_EMAIL: o.author.email, GIT_COMMITTER_NAME: o.author.name, GIT_COMMITTER_EMAIL: o.author.email } : {};
  const commit = (await g(["commit-tree", rootTree, ...(parent ? ["-p", parent] : []), "-m", `shots: ${o.folder}`], env)).trim();
  await g(["update-ref", "refs/heads/pr-shots", commit]);
  if (o.push) await g(["push", "-q", "origin", "refs/heads/pr-shots:refs/heads/pr-shots"]);
  return commit;
}

if (import.meta.main) {
  const [folder, ...files] = process.argv.slice(2);
  if (!folder || files.length === 0) { console.error("usage: bun pr-shots <folder> <file.png>..."); process.exit(2); }
  const repo = (await must(["git", "rev-parse", "--show-toplevel"])).trim();
  const remote = (await must(["git", "remote", "get-url", "origin"])).trim().replace(/^git@github\.com:/, "https://github.com/").replace(/\.git$/, "");
  const sha = await commitShots({ repo, folder, files, push: true });
  console.log("| Screen | Appearance | Picture |\n|---|---|---|");
  for (const f of files) {
    const name = basename(f, ".png");
    const [state, appearance] = name.split(/-(?=dark$|light$)/);
    console.log(`| ${state} | ${appearance ?? ""} | ![${name}](${remote}/blob/${sha}/${folder}/${basename(f)}?raw=true) |`);
  }
}
```
